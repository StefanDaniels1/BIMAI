---
title: Glossary
description: bimai and BIM terms used in these docs, with Dutch equivalents.
---

| Term | Meaning | Dutch |
|---|---|---|
| **Agent** | An AI team member with one job | Agent |
| **Automation** | A workflow that runs on a schedule | Automatisering |
| **BEP** | BIM execution plan: the project's BIM agreements | BIM-uitvoeringsplan (BUP) |
| **Capability** | Something a connector can do, like "read issues" | Vaardigheid |
| **CDE** | Common data environment, e.g. ACC | Gemeenschappelijke dataomgeving |
| **Connector** | A standard bridge to a tool or data source | Koppeling |
| **Cover** | Temporarily taking over a colleague's position | Vervanging |
| **Desk** | Your private part of bimai, across all projects | Bureau |
| **Evidence** | The record of where a statement came from | Bewijs / herleidbaarheid |
| **Gate** | A point where a person must approve or answer | Goedkeuringsmoment |
| **Handoff** | Work passed to the position that owns it | Overdracht |
| **Journal** | Short summary of what a session did | Logboek |
| **Pack** | A reusable BIM procedure: instructions, scripts, tests | Pakket |
| **Position** | A job on the project, held by one or more people | Functie / positie |
| **Rule owner** | A person who approves changes to shared rules | Eigenaar van de afspraken |
| **Seat** | One person's part of a shared project | Werkplek |
| **Uploader** | The person who added a file, e.g. a transcript; gets the questions | Aanleverder |
| **Workflow** | Steps chained in order or in parallel | Werkstroom |
