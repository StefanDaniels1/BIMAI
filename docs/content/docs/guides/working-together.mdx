A viaduct project with three people:

| Person | Role | Their team |
|---|---|---|
| Anna | BIM coordinator | Coordinator, Issue Manager, Scribe |
| Joris | Constructeur | Coordinator, Structural Analyst (SCIA) |
| Fatima | BIM modeller | Coordinator, Model Checker |

Anna started the project; Joris and Fatima [joined](/docs/start/join). Each has a **seat** (their team and
settings) and a **position**: the job on the project, such as `constructeur`. What the agents learn stays with
the position, so a colleague who takes over starts with everything that was done.

## You say it, bimai does it

| You say | bimai does |
|---|---|
| *"Hand this clash to the modeller, with the BCF file."* | `bimai handoff --to bim-modeller`: one file in Fatima's inbox, with the evidence |
| *"What's new for me?"* | reads your **seat brief**: open handoffs, new decisions, the team's activity |
| *"Record that we chose a 300 mm deck slab, from today's meeting."* | `bimai decide`: one decision file, with who decided and the source |
| *"That replaces the 250 mm decision."* | `bimai decide --supersedes <id>`: the old one is marked superseded, never edited |
| *"The duct is moved, close the handoff."* | `bimai handoff --done <id>`, only by the person it was handed to |
| *"What did the team do last week?"* | `bimai log --team --since 7d`, when your project shares the log |

Your team does the typing. You can run the same commands yourself: `bimai inbox`, `bimai decisions`,
`bimai brief`.

## Rules that keep it calm

- **Your work stays yours, theirs stays theirs.** When your team finds something in another position's area,
  for example a clash in Fatima's model, it hands it over instead of fixing it.
- **One file per record.** Handoffs and decisions are each their own file, so two people never edit the same
  file. A decision is never changed afterwards; a new one supersedes it.
- **The shared files are the same for everyone.** `CLAUDE.md` and the team members in `.claude/agents/` don't
  name anyone; what is personal comes from your own seat brief.
- **The session log is yours** unless your project shares it (`log: { share: true }` in `.bimai/project.yaml`).

## Sharing your changes

For now, share the project folder through your project's git (or let IT set that up). bimai's files are laid
out so that two people working at the same time normally never touch the same file. Next, bimai will save and
share for you, without git commands.
