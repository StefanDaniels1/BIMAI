Every tool is reached through a **connector**, and every connector behaves the same way: same safety
rules, same evidence, same tests.

| Type | For | Examples |
|---|---|---|
| **Cloud** | Online services | ACC / Forma, Microsoft 365 |
| **Desktop bridge** | Programs running on your computer | Revit, Civil 3D, Bentley OpenRoads, AutoCAD, Navisworks, Blender/Bonsai |
| **File** | Open formats and exports | IFC, IDS, BCF, OpenUSD, Relatics JSON, Primavera and MS Project XML |
| **Existing MCP server** | Servers others already built | Autodesk AEC Data Model, Revit Public MCP, Autodesk Product Help |

## Capabilities, not brands

Packs ask for a **capability** ("read issues", "query the model", "query alignments"), not a product.
Civil 3D and OpenRoads offer the same infra capabilities, so an alignment check works on either. When a
project moves from ACC issues to BCF, the same pack keeps working.

## Maturity

| Level | Means |
|---|---|
| experimental | Builds; use at your own risk |
| beta | Passes the conformance tests and has recorded test data |
| stable | Beta, used in an evaluation scenario, with a maintainer |
