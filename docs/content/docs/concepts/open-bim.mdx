---
title: Open BIM
description: Vendor tools are connectors; open formats are the long-term backbone.
---

bimai works with the tools teams use today (Autodesk and Bentley) and is built so the same work moves to
open standards without rewriting anything.

| Capability | Today | Open route |
|---|---|---|
| Issues | ACC | BCF |
| Querying models | Revit, AEC Data Model | IfcOpenShell, Bonsai |
| Checking requirements | Checklists | IDS |
| Alignments and corridors | Civil 3D, OpenRoads | IFC 4.3 (`IfcAlignment`) |
| Model exchange | Revit | OpenUSD |

Later, bimai's IFC and OpenUSD enrichment engine will classify elements and record the source of every
machine-made statement, delivered as an IFC file with the additions documented.
