---
title: Join a project
description: When a colleague already started the project. About one minute.
---

<Status state="planned" />

```bash
bimai join https://github.com/your-org/a2-knooppunt
```

The BEP and project settings are already there, so you only answer three questions: your role, what
you want help with, and how familiar you are with VS Code. You're then given (or pick) a **position**,
for example `modeller-structure`, and bimai proposes your team.

The project appears on your desk, and you open it with:

```bash
bimai open a2-knooppunt
```
