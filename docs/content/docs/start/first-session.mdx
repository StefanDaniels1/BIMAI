description: What happens when you open a project, and a few things to try.

<Status state="planned" />

`bimai open a2-knooppunt` opens the project in VS Code with Claude Code ready. Every session starts
the same way:

1. **Update from the team.** bimai fetches your colleagues' latest work.
2. **What's new.** New decisions, work handed to you, your tasks for today, anything waiting for your
   approval.
3. **Your turn.** Ask in plain language, or use a command.

```
/bimai:plan             what should I do today?
/bimai:meeting          process a meeting transcript
/bimai:triage           triage open ACC issues
/bimai:report           weekly design progress report
/bimai:approve          review changes waiting for your approval
```

When you're done, just close VS Code. bimai has already saved your work and shared it with the team:

```
Saved and shared with the team ✓
```
