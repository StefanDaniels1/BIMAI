<Status state="planned" />

```bash
bimai new --demo
bimai open demo
```

The demo project has a BEP, a few colleagues with their own teams, recorded ACC issues and model data,
a Relatics export, a planning and a meeting transcript. Try:

```
/bimai:meeting          turn the sample transcript into minutes and tasks
/bimai:triage           triage the recorded ACC issues
/bimai:report           write this week's design progress report
/bimai:plan             plan my day
```

Nothing you do in the demo touches a real system. It's also the sandbox used for workshops and for
reproducing problems.
